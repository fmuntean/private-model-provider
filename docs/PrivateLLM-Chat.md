# Private Model Provider – Chat Interface Manual

## Overview

The **Private Model** sidebar provides a VS Code webview chat UI backed by your configured OpenAI-compatible server. It is separate from GitHub Copilot Chat and is intended for private, direct interaction with local or self-hosted models.

The chat UI is implemented by:

- `src/ui/chatView.ts`
- `src/ui/assets/index.html`
- `src/ui/assets/main.js`
- `src/ui/assets/style.css`
- `src/provider.ts`
- `src/sessionManager.ts`

## Getting Started

1. Configure `private.model.provider.serverUrl`.
2. Open the **Private Model** activity container.
3. Open the **LMP** webview.
4. Select a model from the dropdown.
5. Type a message and press **Enter** or click **Send**.

Use **Shift+Enter** for multiline input.

## Main Controls

| Control | Action |
|---|---|
| **Model dropdown** | Chooses the model ID sent with new messages. |
| **Send** | Sends the current text to the provider. |
| **Stop** | Sends a stop request to the extension. Full cancellation is limited in the current webview implementation. |
| **Session item** | Opens an existing session from the session list. |
| **Back arrow** | Returns from chat view to the session list. |

The current sidebar does not include Clear Chat, Export, or Import buttons.

## Session Management

- New sessions are created automatically when you send a message with no active session.
- Session titles are generated asynchronously from the first message.
- Title generation uses `private.model.provider.smallModel` when set, otherwise the selected/default model.
- Session metadata is saved to `ai-logs/sessions.json`.
- Messages are saved to `ai-logs/YYYY-MM-DD/HHMM-<sessionId>.jsonl`.
- If no workspace folder is open, sessions are stored in the extension global storage path.

## Prompt Customization

| File | Purpose |
|---|---|
| `.llm/master.md` | Master prompt loaded into conversations when available. |
| `.llm/session.summary.md` | Custom session title prompt. Supports `{{message}}`. |
| `.llm/prompts/<model-id>/system.md` | Model-specific system prompt generated by command. |
| `.llm/prompts/<model-id>/title.md` | Model-specific title prompt generated by command. |

Use `private-model-provider.editMasterPrompt` to edit `.llm/master.md`. This command is registered but is not currently listed in `package.json` command contributions.

## Token Tracking

- The server's final `usage` object is displayed in the chat when available.
- `StatisticsManager` tracks request counts, input/output tokens, response time, and per-model totals.
- Session token usage is tracked by message type in session metadata.

## Troubleshooting

- **No models**: run **Private Model Provider: Test Connection** or verify `GET /v1/models`.
- **LM Studio request failures**: use `http://localhost:1234` without `/v1`, and try disabling `parallelToolCalling`.
- **Tool-call errors**: set `agentTemperature` to `0`, disable `parallelToolCalling`, or disable `enableToolCalling`.
- **Long load times**: increase `private.model.provider.requestTimeout`.

For the implementation sequence, see `docs/sendMessage.md`.
