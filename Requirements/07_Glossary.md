# Glossary

## Overview
This document defines key terms and acronyms used in the Private Model Provider extension requirements and documentation.

---

## A

### API (Application Programming Interface)
A set of rules and protocols for building and interacting with software applications. In this project, refers to the OpenAI-compatible REST API exposed by inference servers.

### API Key
A secret token used to authenticate requests to an API. Stored securely in VS Code's SecretStorage.

---

## B

### Backoff (Exponential Backoff)
A retry strategy where the delay between retries increases exponentially (e.g., 1s, 2s, 4s, 8s) to avoid overwhelming a failing server.

---

## C

### CSP (Content Security Policy)
An HTTP header or meta tag that helps prevent injection attacks by specifying which resources the browser is allowed to load.

### Copilot Chat
VS Code's built-in AI chat interface that supports language model providers via the `vscode.LanguageModelChatProvider` API.

---

## D

### Delta (SSE Delta)
In Server-Sent Events (SSE), a delta represents a chunk of data containing incremental updates (e.g., new tokens in a streaming response).

---

## E

### EventEmitter
A programming pattern used in Node.js and VS Code extensions to emit events and allow multiple subscribers to listen for those events.

### Extension (VS Code Extension)
A package that adds functionality to Visual Studio Code. This project is a VS Code extension.

---

## F

### Function Calling
See **Tool Calling**.

### Finish Reason
A field in the LLM response indicating why the generation stopped (e.g., "stop", "length", "tool_calls").

---

## G

### GatewayClient
The HTTP client class (`src/client.ts`) responsible for communicating with OpenAI-compatible inference servers.

### GatewayConfig
The configuration interface defining all settings for the GatewayProvider and GatewayClient.

### GatewayProvider
The main provider class (`src/provider.ts`) that implements VS Code's `LanguageModelChatProvider` interface.

---

## H

### HTTP (Hypertext Transfer Protocol)
The protocol used for communication between the extension and the inference server.

### HTML (HyperText Markup Language)
The markup language used to create the webview UI (`src/ui/assets/index.html`).

---

## I

### Inference Server
A server that runs LLM inference (text generation). Examples: vLLM, Ollama, llama.cpp.

### Input Tokens
The number of tokens in the prompt (system message + conversation history) sent to the LLM.

### JSON (JavaScript Object Notation)
A lightweight data-interchange format used for API requests and responses.

### JSONL (JSON Lines)
A format where each line is a valid JSON object. Used for storing chat messages (`HHMM-chatId.jsonl`).

### Jitter
A random variation added to retry delays to prevent multiple clients from retrying at the same time (thundering herd problem).

---

## L

### LLM (Large Language Model)
A machine learning model trained on vast amounts of text data to generate human-like text. Examples: GPT-4, Llama 3, Qwen.

### Log Level
A category for log messages indicating severity: debug, info, warn, error.

---

## M

### Memento
VS Code's storage API for persisting data. `globalState` persists across workspace changes.

### Model Cache
An in-memory cache of available models from the inference server, with a configurable TTL (time-to-live).

---

## N

### Nonce
A unique, random string used once, primarily in CSP to whitelist inline scripts in the webview.

---

## O

### OpenAI
The company that created the GPT series of LLMs and the Chat Completions API format.

### Output Tokens
The number of tokens generated by the LLM in its response.

---

## P

### Prompt
The input text sent to an LLM, including system message, conversation history, and current user message.

### Preset
A predefined configuration for a specific inference server (e.g., vLLM preset with URL `http://localhost:8000`).

---

## Q

### (No terms starting with Q)

---

## R

### Reasoning Content
Additional text generated by some LLMs (e.g., OpenAI o1) that shows the model's "thinking" process before the final answer.

### Retryable Error
An error that might succeed if the request is retried (e.g., HTTP 429 Too Many Requests, 503 Service Unavailable).

### Role
The speaker in a conversation: `system` (instructions), `user` (human), `assistant` (LLM), `tool` (function results).

---

## S

### SecretStorage
VS Code's encrypted storage for sensitive data like API keys.

### Server-Sent Events (SSE)
A standard for streaming data from server to client using a single HTTP connection. Used for streaming LLM responses.

### Session (Chat Session)
A single conversation thread with an LLM, containing multiple messages and tool interactions.

### Status Bar
The bar at the bottom of VS Code's window that shows status information and quick actions.

### Streaming
A method of receiving LLM responses incrementally (token by token) rather than waiting for the full response.

### System Prompt
A message with `role: "system"` that provides instructions to the LLM at the start of a conversation.

---

## T

### Temperature
A parameter (0-2) controlling randomness in LLM outputs. Lower values make output more deterministic; higher values more creative.

### Token
A unit of text (roughly 4 characters for English) that LLMs process. Token limits define context window size.

### Tool Calling
The ability for an LLM to invoke external functions (tools) and receive results, enabling actions beyond text generation.

### TTL (Time-To-Live)
The duration for which cached data remains valid before it must be refreshed.

---

## U

### UI (User Interface)
The visual elements users interact with, including the webview chat panel and status bar.

---

## V

### VS Code (Visual Studio Code)
A free, open-source code editor by Microsoft that supports extensions like Private Model Provider.

---

## W

### Webview
A VS Code UI component that renders HTML content, used for the chat interface.
